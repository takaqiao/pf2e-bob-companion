# Bastion of Blasphemies Companion

[English](README.md)

为 PF2e《亵渎堡垒》提供昼夜、天气与冒险管理工具。

- 按章节应用昼夜与天气修正。
- 确认 Party 休息，处理噩梦检定。
- 追踪恩惠、冷却、污秽空气与高塔雷击。
- 在同一页面选择魂心用途、查看预览并确认。
- 与已有 Calendaria 配置同步章节天气。

## 版本与依赖

已核对 Foundry VTT **14.368**、PF2e **8.5.1**，需要 **libWrapper 1.13.5.1+**。冒险管理功能使用官方冒险 **1.0.0** 导入世界后的物品与规则。昼夜、天气规则也可手动指定章节。

Calendaria **1.4.2** 为可选依赖；同步需要已有的 BoB 章节区域与天气预设，不会新建历法。

## 安装

在 Foundry 模组安装器中填写：

```text
https://github.com/takaqiao/pf2e-bob-companion/releases/latest/download/module.json
```

启用本模组与 libWrapper 后刷新。GM 可从模组设置的 **BoB 冒险管理** 进入，也可在角色目录的环境面板中打开 **冒险管理**。

## 首次设置

1. 在环境面板确认章节与时间。用 **场景准备** 纳入地图，并标记室内或避风避雨区域；官方主岛默认纳入。
2. 在 **休息 → 高级** 中记录此前首夜是否已处理。之后 Party 休息会汇总为待办，由 GM 确认实际睡眠成员。
3. 为环境危险和房间恩惠绑定区域，再启用对应追踪。
4. 旧战役可在 **魂心 → 高级** 核对已有累计生命值奖励，也可为新角色补齐。

魂心预览显示实际物品数量、魅影阶位，以及每位角色的生命值变化。恢复与纠正在高级设置中；操作中断时使用已有待办重试。

剧情前提、实际暴露、反制与伤害仍由 GM 确认。玩家只看到当前检定与已获得的效果。研究继续使用原有场景。

## 语言

完整提供简体中文和英文，跟随各客户端的 Foundry 语言。中文兼容 `cn` 与 `zh-cn`。本模组创建的效果名称、说明和带翻译标记的聊天信息按查看者语言显示。自定义名称与其他模组内容沿用各自翻译；旧聊天保留原文字。

## 设置与性能

环境面板分为总览、场景准备、高级三页。同一环境中的普通移动不重新准备角色；正常走时仅在相关状态变化时保存危险记录，不增加逐帧扫描或定时轮询。

暂停环境规则也会暂停自动接入休息、危险追踪与恩惠条件更新，保留已完成奖励和记录。停用模组不会删除已保存的物品与效果，请在其剧情条件结束时移除。

Calendaria 同步会保留手动天气至下一章，或由 GM 恢复自动。沿用世界钟与冒险原有音画设置。

## 源码

运行 `node --test tests/*.test.mjs` 执行测试。在 PowerShell 中运行 `./build.ps1` 构建安装包。安装包包含程序、语言、说明与三个可选入口宏，不包含测试或冒险资产。

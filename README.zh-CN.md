# Bastion of Blasphemies Companion

[English](README.md)

PF2e《亵渎堡垒》的 GM 工具，管理昼夜天气、休息噩梦、恩惠、环境危险与魂心

日常检定在聊天卡中处理。模组设置 → **BoB 维护工具** 用于首次设置、修正与恢复

## 安装

在 Foundry 模组安装器中填写：

```text
https://github.com/takaqiao/pf2e-bob-companion/releases/latest/download/module.json
```

启用模组与 libWrapper 后刷新

已核对 Foundry VTT **14.368**、PF2e **8.5.1**、libWrapper **1.13.5.1+**。冒险管理需要官方冒险 **1.0.0** 已导入的内容；环境规则也可手动指定章节

可选 Calendaria **1.4.2**，需已有 BoB 章节区域与天气预设

## 首次设置

1. 在环境面板确认章节与时间，用 **场景准备** 纳入地图并标记遮蔽区域；官方主岛默认纳入
2. 打开 **休息与噩梦**，记录此前首夜是否已处理
3. 绑定环境危险区域与恩惠房间
4. 旧战役在 **魂心 → 高级** 核对累计生命值奖励，也可为新角色补齐

## 使用

| 入口 | 操作 |
| --- | --- |
| 休息与噩梦 | 原生休息后，在 GM 聊天卡确认睡眠成员；投掷豁免，再应用已记录结果 |
| 恩惠 | 声明使用后在聊天中处理检定；原生掷骰实际使用冥想加值后，自动标记已用 |
| 环境危险 | 在 GM 聊天卡投掷待办检定，再应用结果；伤害等手动后果由 GM 确认 |
| 魂心 | 选择用途，核对数量、阶位与生命值变化后确认 |

聊天卡会原位更新并防止重复应用。剧情前提、反制、事后加值与伤害仍由 GM 确认。修正与恢复在 **维护工具 → 高级** 中，魂心操作中断时继续已有待办

暂停规则会保留奖励和记录，同时暂停休息接入、危险追踪与恩惠条件更新。停用模组后，已有物品与效果仍保留，剧情条件结束时需移除

Calendaria 手动天气保留至下一章，也可手动恢复自动同步

中英文跟随各客户端语言，中文支持 `cn` 与 `zh-cn`。玩家仅看到当前调整，不显示未揭示的触发条件或未来后果；详细结算卡仅发送给 GM
